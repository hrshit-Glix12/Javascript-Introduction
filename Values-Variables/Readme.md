# What is valus & varibales ?
- A variable is a container like box that holds value.It has a name and can be used 
  to store and manipulate data in program.
- Values : value is piece of information.

# Varibale Rules & Regiularity:
- variable name start with letter ,an underscore(_) or doller sign($).
- Variable name not contain space.
- Variable cannot be the same as reserved keyword such as is or const. e.g where,name 
- Variable names are case-sensitive. e.g Hi is not equal to hi.
- By converstation in Javascript varibale names written in camelCase.
- Variable name can be as long as you need.
